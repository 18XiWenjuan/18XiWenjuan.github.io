# 奚文涓个人主页

基于简历制作的响应式学术个人主页，纯静态 HTML/CSS，无需安装依赖。

## 发布到 GitHub Pages

1. 在 GitHub 新建名为 `USERNAME.github.io` 的 public repository。
2. 将本目录中的 `index.html` 和 `README.md` 推送至仓库默认分支根目录。
3. 在仓库的 **Settings → Pages** 中选择从默认分支根目录发布。
4. 页面地址为 `https://USERNAME.github.io/`。

页面只包含用于职业介绍的经历与学术成果；没有公开简历中的电话、住址、出生年月或邮箱。简历没有提供的论文、代码仓库和社交链接均未添加。
