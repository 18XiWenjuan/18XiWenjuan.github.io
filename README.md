# Wenjuan Xi — Academic Homepage

A responsive, static personal homepage built with plain HTML and CSS. No dependencies or build step are required.

## GitHub Pages

This site is published at [https://18xiwenjuan.github.io/](https://18xiwenjuan.github.io/). Its source is in the `18XiWenjuan.github.io` repository.
